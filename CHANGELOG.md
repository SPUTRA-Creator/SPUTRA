# Changelog

## Version 1.0.0

Initial public release of SPUTRA.

Features:

* Monte Carlo simulation of sputtered-particle transport
* SRIM-type target-emission stage (sputtering yield, Sigmund-Thompson
  energy distribution, cosine angular emission)
* SIMTRA-type gas-phase transport with hard-sphere binary-collision
  kinematics and an energy-dependent mean free path
* Three-channel particle-fate accounting (deposited / wall-lost /
  thermalized), exactly conserved
* Reactive-gas support
* Pressure-sweep capability
* Two-dimensional thickness heatmaps
* Radial thickness profiles
* Three-dimensional trajectory visualization
* Integrated verification and validation
* Export of numerical results and figures (CSV / JSON / PNG)
