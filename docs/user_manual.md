# SPUTRA User Manual

## Overview

SPUTRA is a Monte Carlo sputtered particle transport simulator
for magnetron sputter deposition studies.

## Running

1. Launch `SPUTRA.exe`
2. Select target material
3. Select process gas
4. Set pressure
5. Set voltage/current
6. Run simulation

## Outputs

- Deposition heatmap
- Radial thickness profile
- 3D particle trajectories
- Pressure sweep analysis
